## 各维：现状 / 缺口 / 满分路径下一可执行交付

### D1 可调用执行与产物完整性 — 级 4

- **现状**：`ToolRuntime` / `ArtifactStore`；COMPLETED / FAILED / BLOCKED 三分；有界读取；wheel 含 23 模块；a5 安装子集 464 节点、源码可移植+SDK 共 2992 唯一节点（Release 正文）。
- **缺口**：任务级独立验收权威、人工/科学复核、回滚、通用持久恢复未闭环（crosswalk F01）。
- **下一交付**：一个**公开合成**「任务验收回执」示例：成功/拒收/未知三分母 + 独立 SHA-256 复核脚本；不引入私密科研数据。

### D2 来源审计、准入与供应链 — 级 3

- **现状**：`source_audit` / `source_admission`；本地 pin；私密 audience 门控；Release 隐私审查称零未解决发现（有界、非认证）。
- **缺口**：跨项目撤权/保留/禁止导出（F13 PROPOSED）；认证供应链与恶意隔离未证明。
- **下一交付**：合成负例包——篡改 manifest、越权导出、私密字段误入 public audience 必须失败；文档写清「哈希≠授权」。

### D3 持久任务恢复与副作用对账 — 级 2

- **现状**：PR #48 合并有界固定 DAG 源码与兼容；ADR 008 设计冻结；兼容跑记录覆盖 pure/SDK 与原参考服务例，**新 DAG 服务恢复 NOT_RUN**（crosswalk / ADR）。
- **缺口**：进程崩溃 fencing、提交前后中断对账、取消生命周期、外部副作用真实性 NOT_PROVED。
- **下一交付（小 PR）**：在**已授权本机 Temporal 参考环境**跑一条「发布后注入投递失败 → Update 对账 → B 仅在 A 原结果确认后启动」的**真服务**门禁；产出 Actions/本地回执；明确仍非多机证明。

### D4 HTTPS / 外部智能体互操作 — 级 2

- **现状**：显式导入 `a2a_http_transport`；有限 mock/BytesIO；代理/CA 环境拒绝；A2A 返回 UNACCEPTED。
- **缺口**：live network / worker / provider / model / Codex **全部 NOT_RUN**（Release + README）。本项目约束：**禁用 Codex CLI/云任务**。
- **下一交付**：在用户本机/dot 额度下，对**自有测试 HTTPS worker**做一次有界 live 交换（固定字节上限、无密钥入仓）；失败则保留 mock-only 边界，不宣称互操作。

### D5 CAD/CAE 领域工作流 — 级 2

- **现状**：固定 CAD→mesh→thermal 配方与虚构 fixture；公开 STEP 历史投影字节检查（STEP SHA-256 见 a5 notes）；原生完整链 NOT_RUN。
- **缺口**：物理验证 NOT_PERFORMED；网格无关性未建立；独立内核未评。
- **下一交付**：可选「同内核只读重放」小门禁（若本机已有 Open CASCADE）；否则保持 NOT_EXECUTED，只统一文档表述。

### D6 Temporal 有界服务证据 — 级 3

- **现状**：历史单机 loopback：queued first delivery、记录结果重放；批次摘要 200 合成终端等（历史范围，不可加总当规模）。
- **缺口**：非 200 agents；CPU 并行未评；原始 per-job 证据不完整。
- **下一交付**：把「历史证据范围」与「当前 a5/main 是否重新合格」在 CAPABILITIES 做一页对照表，避免证据漂移。

### D7 科研证据链与科学验收 — 级 2

- **现状**：假设卡/来源审计部分机制；测量比较六行合成；`scientific_accepted` 恒 false。
- **缺口**：**科研端到端**（假设→计算→独立复算→反例）NOT_RUN。**私密科研不得进入公开仓**（见 `DESENSITIZE_CN.md`）。
- **下一交付**：仅用**公开合成或公开数据集**的最小「证据包」模板（来源清单、参数、复算入口、未知项）；私密课题另仓/本地。

### D8 多机 / 多 Dot 协同与规模 — 级 2

- **现状**：对标方向存在于研究文档；实现上无真实多机、无真实外部多智能体测量。
- **缺口**：用户粘贴所称最大缺口——**真实外部智能体 / 多机 / 科研端到端**——与公开证据一致。
- **下一交付**：设计一页「双机只读协同协议」草案（身份、预算、产物交换、拒绝规则），**先文档 PR**，不声称已实现。

### D9 上手文档与首结果旅程 — 级 4

- **现状**：a5 Release 前缀：EN/ZH 安装指南块 **1–6、8 PASS**；块 7 Git **NOT_RUN**；五文件资产与外部 manifest pin。
- **缺口**：首页示例与中英文档路径偶发漂移；新贡献者仍易混淆 wheel / sdist / full-source。
- **下一交付**：统一「三种资产选哪一个」对照表到 README + `installed-quickstart` 顶端；首页加一条 30 秒合成示例链接。

### D10 主张边界与公开发布纪律 — 级 4

- **现状**：全文坚持 ALPHA / NOT_SCORED；不声称机构背书、生产就绪、科学/设备权限。
- **缺口**：对外传播若脱离证据易越界；**发帖到 X 在安全确认未解前禁止**。
- **下一交付**：维护「允许说 / 禁止说」清单 PR（见 `NEXT_PRS_CN.md`），任何对外文案先对账 CAPABILITIES。
