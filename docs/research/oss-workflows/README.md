# OpenDot workflow benchmark / 工作流对标

Observed 1 October 2026 UTC. This public-source research package supports a bounded synthetic workflow. It does not authorize publication, change the readiness score or establish platform maturity.

## Main finding / 主要结论

Connect exact inputs, result bytes and independent acceptance in one small reviewable workflow before expanding runtime claims. The example's checking mechanics were independently exercised; real user usefulness, unaided onboarding and time savings remain unverified.

先把精确输入、结果字节与独立验收连接成一个可审阅的小型流程。已独立核对示例机制；真实用户价值、无人指导上手和节时收益仍待验证。

## Limits / 范围限制

GitHub stars are a mutable attention gauge, not quality, users or performance. Current OpenHands/OpenHands is beta Agent Canvas; the Python SDK/Agent Server and scheduling belong to separate repositories. DVC's current verified repository is treeverse/dvc. AiiDA and Bluesky are retained for scientific workflow relevance, not described as high-star projects.

Peer documentation and metadata were inspected. Peer installations, support responsiveness, release signatures and performance were not tested. Root license text is not a full component/dependency license audit. No affiliation, endorsement, customer demand, controlled user study or scientific qualification is implied.

星数不等于质量、用户数或性能；同行源代码、文档与发行元数据不是本项目的能力证明。没有执行同行软件、联系维护者或开展用户研究。结果核对不等于任务恢复，CAS 完整性不等于科学正确性。
