# 私密科研 → OpenDot 公开仓 脱敏检查清单（中文）

- 编制：2026-10-25（Asia/Shanghai）
- 适用范围：任何拟写入 `sddvacav/opendot`（或公开 Fork/Release/Issue/PR/Actions 日志）的内容
- 硬规则：**私密科研材料不得进入 OpenDot 公开仓**；OpenDot 只承载可公开复现的工程能力与合成/公开证据
- 本清单**故意不收录**任何具体私密构型、成分、计算参数、机房或未发表结论

## 1. 决策流（每次提交前）

```
拟公开？
 ├─ 否 → 留在私有仓 / 本机加密盘；OpenDot 仅可引用「能力缺口类型」级描述
 └─ 是 → 过下列闸门；任一闸失败 = 禁止合入公开仓
```

## 2. 绝对禁止进入公开仓的类别

| 类别 | 示例（类型级，非实例） | 处理 |
| --- | --- | --- |
| 未发表材料体系与工艺 | 合金牌号配方、热处理制度、未公开试样编号 | 私有仓；公开侧用「合成材料 / 公开教材算例」 |
| 未发表显微/衍射原始数据 | TEM/EDS/XRD/EBSD 原始图、谱、私有路径 | 私有；公开仅用权利清晰的开放数据或合成 fixture |
| 未发表计算结果与轨迹 | 私有 DFT/MD 输入输出、波函数、轨迹、能量表 | 私有；公开用合成数值或已发表补充材料 |
| 内部执行现场 | 主机名、内网 IP、GPU UUID、进程 PID、队列账号 | 删除或泛化为 `worker-a` / `localhost` |
| 身份与凭证 | Token、SSH 钥、许可证服务器、邮箱、真名通讯录 | 永不入库；用 vault/本机环境变量 |
| 合作方未授权信息 | 对方未公开的技术指标、商务条款 | 默认拒绝 |
| 可还原私密问题的「过度具体」描述 | 精确原子数+掺杂元素+加载路径组合到可指认课题 | 改为抽象：「有界剪切差分合成算例」 |

## 3. 允许进入公开仓的替代物

| 允许 | 要求 |
| --- | --- |
| 合成 CSV / JSON fixture | 文档标明 `synthetic` / `invented`；`scientific_accepted=false` |
| 已在 OpenDot 的公开 STEP / 测量六行示例 | 保持既有 pin 与许可 |
| 能力与缺口的**类型**描述 | 如「真实外部 HTTPS worker NOT_RUN」——不附私有 URL 密钥 |
| 已发表论文 / 开放预印本 / 官方政策链接 | 可核验 URL；阅读范围写清 |
| 脱敏后的架构图 | 无内部主机名、无试样编号 |

## 4. 提交前逐项核对（复制到 PR 描述）

- [ ] 本 diff **不含**私有仓路径、试样 ID、未发表图表
- [ ] 本 diff **不含**真实材料化学计量/掺杂/工艺到可指认程度
- [ ] 日志已去掉主机名、绝对家目录、PID、账号
- [ ] 新增 fixture 已标 synthetic 或已验证开源许可
- [ ] 文档未声称科学验收通过 / 机构背书 / 满分
- [ ] 未附上仅内部可访问的链接（或已标 BLOCKED 且无正文摘录）
- [ ] Actions 工件与测试输出同样过本清单（防日志泄漏）
- [ ] 若从私有课题「总结经验」：只抽象为 OpenDot 产品需求（恢复/证据链/边界），无课题指纹

## 5. 双仓工作流（推荐）

| 仓 | 内容 |
| --- | --- |
| 私有科研仓 | 全部原始数据、计算、论文初稿、内部优先级 |
| OpenDot 公开仓 | 通用运行时、合成示例、公开研究映射、有界合格证据 |

跨仓引用规则：

- 公开 → 私有：**禁止**（链接会泄漏存在性与结构）
- 私有 → 公开：仅引用 **Release 标签 / 公开文档锚点**，不反向链到私有路径
- 需要共同术语时，用中性词：`artifact`、`receipt`、`NOT_RUN`，避免私有项目代号进 OpenDot 标识符

## 6. 发布 / Issue / 对外传播额外闸

- Release notes、Discussions、Issue：**同等脱敏**
- **发帖到 X：安全确认未解前禁止**（与用户约束一致）
- 对外演示：只用公开五文件包 + 合成示例；不投屏私有科研目录
- 若误推送：按 SECURITY.md 作密钥轮换与历史清理评估；假设已泄漏

## 7. 与 OpenDot 现有机制对齐

- `source_audit` 的 `audience=public|private`：私有材料不得标 public
- 产物回执保持 `scientific_accepted=false`，除非另有**独立科学审查协议**（目前公开仓未建立）
- crosswalk / RESEARCH-MAP 只映射**公开信息源**；私有课题需求不进 22-need 正式表，除非完全抽象且无指纹

## 8. 快速失败口令

出现以下任一字符串模式时，暂停合并并人工审查（可按项目扩展）：

- 私有仓库名、内网域名、`/home/` 下个人课题路径
- 「未发表」「内部口径」「勿外传」
- 许可证服务器地址、`API_KEY`、`BEGIN .* PRIVATE KEY`
- 可指认的具体试样/炉次/批次编号样式

（具体私有项目名与参数**不要**写入本清单正文，以免清单本身成为泄漏面；在私有 runbook 维护正则。）
