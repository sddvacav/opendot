Component receipts describe their exact code and scopes, not the whole source
integration. Test selections must be collected and deduplicated after integrating
all changes. The new portable delivery manifest has 45 cases: 35 example checks
and ten lock checks. The final selection contains 1,192 distinct cases: 1,033 portable, 78 existing
controlled Git and 81 new source-inventory cases. These counts do not assert a
run outcome. Controlled Git/source-inventory tests are separately selected
only on the supported trusted Git 2.52+ POSIX environment. Repeated installed
checks are not additional unique cases.

The existing runtime package has separate a4 acceptance and consumer-replay
receipts. Replaying archived native results does not run a new solver. Fake lab
plans use internally constructed fake devices only; dependency extensions are
not physical instruments. Structural strain/energy consistency is still a known
unclosed scientific-verifier boundary. Standalone molecular-dynamics tests do
not constitute an integrated OpenDot solver adapter.

Generated receipts, optional dependencies, native executables and private project
records are not bundled here. No hosted CI, official public repository/registry,
human usability validation, multihost scheduling, autonomous agent platform or
full release/rights/security clearance is established by this extension.
