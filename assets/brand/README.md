# OpenDot brand assets

These six SVG files are newly authored AI-assisted vector artwork for this repository. They are not recovered copies of earlier artwork, and no earlier approval, ownership, or hash identity is claimed. See the [asset notice](NOTICE) and the repository's existing [Apache-2.0 license](../../LICENSE).

## Files

- [Light mark](opendot-mark-light.svg) and [dark mark](opendot-mark-dark.svg): 64 × 64, transparent
- [Light wordmark](opendot-wordmark-light.svg) and [dark wordmark](opendot-wordmark-dark.svg): 432 × 104, transparent
- [Light banner](opendot-readme-banner-light.svg) and [dark banner](opendot-readme-banner-dark.svg): 1280 × 360, opaque

The suffix describes the surrounding surface. Use the light version on a light page and the dark version on a dark page. Preserve proportions and leave space around the mark. Start at a 32 px mark canvas or 280 px wordmark width, then check legibility in the actual presentation. Use a mark rather than compressing a banner into a small icon.

The README uses a theme-aware picture with a light fallback and `OpenDot` alternative text. Each SVG has a title, description, image role, and linked accessible label. When inlining several files, give title/description IDs unique prefixes and update the label references.

The geometric lettering uses paths; the SVGs contain no imported fonts, raster images, scripts, external resources, badges, scores, endorsements, or product capability claims. The navy/teal palette should be rechecked for contrast after any background or color change. This is not a complete accessibility certification.
